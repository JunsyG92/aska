# Code de conduite

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/), version 2.1.

## Notre engagement

Nous, contributeurs et mainteneurs, nous engageons à faire de la participation à
ce projet une expérience exempte de harcèlement pour tout le monde, quels que
soient l'âge, la morphologie, le handicap visible ou invisible, l'origine,
l'identité ou l'expression de genre, le niveau d'expérience, l'éducation, la
situation sociale ou économique, la nationalité, l'apparence, la religion ou
l'orientation sexuelle.

## Ce que nous attendons

- Faire preuve de bienveillance et de respect.
- Accueillir les points de vue différents et les débutants.
- Donner et recevoir les critiques de façon constructive, sur le code et non sur les personnes.
- Reconnaître ses erreurs et en tirer des leçons.
- Privilégier ce qui sert la communauté et le projet.

## Ce qui n'est pas acceptable

- Le langage ou les images à caractère sexuel, les avances non désirées.
- Les insultes, les commentaires dénigrants, les attaques personnelles ou politiques.
- Le harcèlement, public ou privé.
- La publication d'informations privées d'autrui sans son accord.
- Tout comportement raisonnablement inapproprié dans un cadre professionnel.

## Application

Les mainteneurs clarifient et font respecter ces règles. Ils peuvent retirer,
modifier ou refuser commentaires, commits, code et issues qui ne les respectent
pas, et exclure temporairement ou définitivement une personne.

Pour signaler un comportement, contactez en privé un mainteneur listé dans
[`.github/CODEOWNERS`](.github/CODEOWNERS). Les signalements sont traités avec
discrétion, et la personne qui signale est protégée.

Ce code s'applique dans tous les espaces du projet (issues, PR, discussions) et
lorsqu'une personne représente publiquement le projet.
